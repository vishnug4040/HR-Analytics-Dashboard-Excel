# HR Analytics Dashboard | Excel

## Project Overview

Developed an interactive Excel dashboard to analyze employee attrition, salary distribution, job satisfaction, workforce demographics, and employee retention.

## Key Analysis

* Employee attrition by department and job role
* Salary analysis by department and job role
* Employee distribution by age and tenure
* Attrition analysis based on overtime and job satisfaction
* Employee exit reason analysis

## Tools Used

* Microsoft Excel
* Data Analysis and Visualization
* PivotTables and PivotCharts 

## Business Objective

To identify workforce patterns, explore employee attrition, and support data-driven HR decision-making.
